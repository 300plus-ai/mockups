300Plus — clickable mockups

Standalone builds of the three front-ends, running on in-memory dummy data. No API, no backend, no network calls.

Client console /client
Jobs, config wizard, candidates & resumes, pipeline graphs, results review, users, share links.
Candidate exam /exam
Invite landing → guidelines & consent → intro → HR/technical/coding questions → submit → feedback. Media capture is simulated.
Super-admin console /super-admin
Platform operator app: tenants, cross-org users, Act-as, audit log, credit rates & grants, ops/cost.

Each mockup lands already signed in and every screen is reachable. Changes persist in memory for the session only — a refresh resets to the seed data. Video playback in the client results screen and real camera/microphone capture in the exam are inert by design.
